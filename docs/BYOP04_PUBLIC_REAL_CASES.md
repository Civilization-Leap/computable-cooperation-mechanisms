# CCM-BYOP-04｜首批公开真实问题试填

本文件用于检验 BYOP 入口本身是否真的能承接现实问题，而不是检验参与者是否认同项目。

原则：只使用公开、非敏感、可引用的事实；不补造未公开事实；不把现实争议压缩成“工具已经解决”；无法表达的部分必须保留为 UNKNOWN 或 REPRESENTATION GAP。

---

## Case A｜企业并购与竞争影响：Microsoft / Activision Blizzard

### 公开事实锚点

美国联邦贸易委员会曾对 Microsoft 收购 Activision Blizzard 提起竞争执法挑战，理由包括担忧合并后可能影响主机、订阅和云游戏领域的竞争。FTC 该案页面目前标记为 Closed。

公开来源：
- https://www.ftc.gov/legal-library/browse/cases-proceedings/2210077-microsoftactivision-blizzard-matter
- https://www.ftc.gov/news-events/news/press-releases/2022/12/ftc-seeks-block-microsoft-corps-acquisition-activision-blizzard-inc

### 主体目的

- 收购方：获得内容、规模、协同与长期竞争优势。
- 被收购方：获得交易价值、资本与整合机会。
- 竞争对手：避免关键内容、渠道或基础能力被竞争者控制。
- 消费者：价格、可得性、创新和选择。
- 监管者：维护竞争秩序。

### 候选安排

1. 完整并购；
2. 并购 + 访问/许可承诺；
3. 长期商业合作但保持独立；
4. 不交易 / 保持现状。

### 当前工具可表达

- 各主体已声明的成本/收益变化；
- 某些可明确写出的硬约束；
- 多候选方案相对共同 baseline 的比较；
- 公开未知项保持 UNKNOWN。

### 当前工具不能证明

- 市场定义是否正确；
- 未来排他行为概率；
- 反垄断法律结论；
- 承诺在多年后是否可信；
- 消费者长期创新损益；
- 交易是否“应该”获批。

### 初步反馈分类

- F — DOMAIN EXTENSION：并购/竞争分析需要重复出现的“控制权、访问承诺、市场结构、长期行为约束”模板。
- A — REPRESENTATION GAP：当前 v0.1.1 缺乏动态市场结构与承诺可信度表达。

## Case B｜平台治理：Apple App Store 与欧盟 DMA

### 公开事实锚点

欧盟委员会在 2025 年认定 Apple 违反 DMA 的 anti-steering 义务，并处以罚款；相关规则要求开发者能够向用户告知 App Store 外的替代优惠与购买渠道。Apple 也公开提供其 DMA 合规材料。

公开来源：
- https://digital-strategy.ec.europa.eu/en/news/commission-finds-apple-and-meta-breach-digital-markets-act
- https://digital-markets-act.ec.europa.eu/developer-portal/app-distribution_en
- https://www.apple.com/legal/dma/

### 主体目的

- 平台：生态安全、体验一致性、收入与平台治理能力。
- 开发者：触达用户、选择商业渠道、降低依赖与费用。
- 用户：安全、便利、价格与选择。
- 监管者：可竞争性与公平市场条件。

### 候选安排

1. 高度集中式平台分发与支付；
2. 允许外部引导与替代购买；
3. 允许第三方商店/网页分发，同时保留平台安全要求；
4. 不同收费与合规结构的组合。

### 当前工具可表达

- 各主体在费用、渠道选择、风险负担等维度的声明变化；
- 开发者或用户的硬保护线；
- 不同规则方案的静态比较。

### 当前工具不能证明

- 安全风险的真实概率；
- 平台收费是否合理；
- 监管义务的法律解释；
- 动态生态反馈；
- 市场力量变化。

### 初步反馈分类

- C — MISSING ACTOR / IMPACT：终端用户、第三方开发者、支付服务商、竞争平台都可能是承重主体。
- F — DOMAIN EXTENSION：平台治理需要“规则制定者—商业用户—终端用户—外部渠道”的重复模板。

## Case C｜高后果 AI 治理：自主武器国际规则

### 公开事实锚点

2026 年 8 月，联合国秘书长与红十字国际委员会主席再次呼吁各国就自主武器系统尽快建立新的国际规则，强调技术发展速度与法律约束之间的差距正在扩大，并特别关注机器自主选择和攻击人类目标的风险。

公开来源：
- https://www.ungeneva.org/en/news-media/press-release/2026/08/renewed-call-united-nations-secretary-general-and-president

### 主体目的

- 国家/军方：安全、威慑、减少己方人员暴露、维持技术优势。
- 对手国家：避免战略劣势与突袭风险。
- 平民与社会：降低误伤、失控、责任断裂与扩散风险。
- 国际组织：建立最低共同规则与问责边界。

### 候选安排

1. 无新增国际限制；
2. 禁止特定自主攻击情形；
3. 对部分系统设置人类控制、可追责、可审计要求；
4. 分阶段、可验证的国际约束与透明措施。

### 当前工具可表达

仅限治理层面：
- 各方声明的安全收益与风险；
- 某些硬约束；
- UNKNOWN；
- 第三方承重；
- 不同制度安排的静态比较。

### 当前工具不能、也不应尝试做

- 武器目标选择或作战优化；
- 具体战术部署；
- 攻击方案比较；
- 战场效能计算；
- 战争正当性裁决；
- 对现实武器使用的授权。

### 初步反馈分类

- D — MISSING CONSTRAINT：不可逆升级、责任断裂、扩散阈值需要独立于普通收益的表达。
- A — REPRESENTATION GAP：v0.1.1 不具备动态升级链、扩散过程和多阶段承诺建模。
- E — MISINTERPRETATION RISK：高后果领域最容易把“可计算”误读为“已被正当化”。

# 三个真实问题对 BYOP 的共同检验

这三例暴露出几个重复结构：

1. 现实问题几乎都不是单一的“合作 / 不合作”；中间存在多个制度安排。
2. 第三方经常不在谈判桌上，却承担结果。
3. 静态 delta 容易表达；动态承诺、权力、长期行为和不可逆路径更难表达。
4. “谁设阈值”与“阈值怎么算”必须分开。
5. 一个工具最有价值的结果可能不是给出结论，而是明确说：这里仍然无法被当前模型无失真表达。

因此 BYOP-04 的首轮结论不是扩核心，而是继续积累重复出现的结构，再决定哪些应成为 reusable template、domain extension，哪些必须长期留在软件之外。
