# Method and boundaries — DEV-1

The software operationalizes only a narrow engineering subset: explicit actors, comparable outcome dimensions, current declared resources, hard constraints, unknown preservation, and deterministic recomputation.

It deliberately does not implement a total utility score, automatic fairness label, motive inference, real-world decision authority, or the full MASTER/WP/FNX research-state machinery.

The public teaching fixture is independently authored for software demonstration. It must not be described as evidence from the formal blind B2B fixture.
