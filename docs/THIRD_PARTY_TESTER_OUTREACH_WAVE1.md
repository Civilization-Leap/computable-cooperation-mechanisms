## Selection method

The first wave uses three different tests rather than three requests for a
general opinion:

1. software testing and counterexample discovery;
2. open-research reproducibility and newcomer usability;
3. civic-tech review of rule provenance and affected-party contestability.

Each message asks for one bounded task, states that endorsement is not requested,
uses no attachment or tracking link, and accepts failure or a counterexample as
a useful result.
