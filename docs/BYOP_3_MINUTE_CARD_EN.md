# BYOP: Three-Minute Problem Card

> You do not need to understand CCM first, and you do not need to know how to model a system. Start by making one real problem visible.

## Start with three questions

1. **Who benefits?**  
   Which people, teams, companies, platforms, or other actors gain from the current arrangement or proposed option?

2. **Who bears the cost?**  
   Who bears cost, risk, extra work, exit difficulty, or other consequences? Is someone outside the negotiating table still carrying the burden?

3. **What do we actually not know yet?**  
   Which key facts, causes, responsibilities, future effects, or intentions are still uncertain? Do not turn UNKNOWN into zero, and do not automatically replace it with the worst case.

## One check before submitting

- Did I write “my interest” as if it were “everyone's interest”?
- Is there a third party with little voice but real burden?
- Did I treat an unknown fact as known?
- Did I turn a negotiable preference into an absolute hard constraint?

If any answer is “maybe”, you can still submit. **An incomplete problem is still useful evidence.**
