# 为什么不是“用个 AI 也能做到”？

> **AI / Agent 负责“看、想、算、做”；CCM 负责“谁得到什么、谁承担什么、哪些不能越、哪里还不知道、何时必须停下来重新判断”。**

很多人第一次看到 CCM，会自然问：这些分析让一个足够强的大模型多想几个角色、多列几个风险，不就可以了吗？

如果只看一次对话里的文字输出，这个判断并不奇怪。AI 的确可以模拟多方立场、列利益与损害、提醒第三方风险，也可以生成很完整的建议。

但 **AI 有能力做到一件事，不等于这件事已经成为可重复、可审计、可拒绝、可降级的机制。**

CCM 不是另一种更聪明的 AI，也不是一个更长的 Prompt。它试图把多主体竞争合作中的关键约束，从“模型这一次有没有想起来”变成“系统必须面对的显式结构”。

## 三者解决的不是同一个问题

| | 传统 AI | 高级 Agent | CCM |
|---|---|---|---|
| 首要问题 | 答案是什么？ | 怎样把目标做成？ | 目标做成后，谁得到什么、谁承担什么？ |
| 目标 | Prompt / 训练偏好 | 任务函数 / 工作流 | 主体目的显式进入，但系统不替主体设定 |
| 多主体 | 可以模拟 | 可以协作或博弈 | 主体分离是一级结构 |
| 第三方 | 容易遗漏 | 常不在任务目标内 | 必须显影不在谈判桌上的承重者 |
| UNKNOWN | 容易继续猜或概率化 | 倾向继续规划与执行 | 可以保持 UNKNOWN，不能被收益覆盖 |
| 硬约束 | 规则 / safety policy | 权限 / guardrail | 与普通收益分离，不能补偿性抵销 |
| 正当性 | 通常不是核心对象 | 成功完成任务是主要标准 | 计算、事实、正当性、授权彼此分离 |
| 新证据 | 重答 | 重规划 | 可以正式升级、降级、冻结、撤回 |
| 扩散 | 很少成为问题 | 以部署成功为主 | 还要问“值不值得扩散”、是否会被反向利用 |

## 普通 AI 可以模仿输出，但不能因此替代机制

让 AI 回答“请分别分析各方利益、第三方风险和未知项”，可以得到一份很好的分析。

但 CCM 还要求：

- **主体必须分开。** 一方的收益不能自动吞掉另一方的损失。
- **第三方必须进入。** 没坐在桌前，不等于没有承担结果。
- **UNKNOWN 必须留下。** 结果未知、原因未知、责任未知、意图未知，不应自动被填成同一个答案。
- **硬约束不能被买掉。** 再大的局部收益，也不能自动抵销已声明的硬边界。
- **计算不制造正当性。** 机器可以精确执行阈值，却不能因为算得准就获得决定阈值为何如此的权力。
- **证据必须分级。** 维护者自跑、外部 AI、独立执行、领域采用不是同一强度的证据。
- **结论必须可降级。** 新证据出现后，曾经的 PASS、采用或扩散都可以被正式降级。
- **扩散前还要过方向门。** 一个高效方案也可能只是更高效的压榨方式。
- **必须检查反向利用。** 显影弱势主体的脆弱边界，也可能帮助强势方更精准施压。

如果这些都没有，只是让大模型“多想几个角度”，那是一次较好的 AI 分析，**不是 CCM**。

## 一个最短的可复现实验

在公开教学案例中：

- A 和 B 的成本各从 8 降到 5；
- 第三方 C 的损失始终是 0.5；
- 当声明的第三方保护上限是 1、0.6、0.5 时，判定为 `SATISFIED`；
- 只把保护线上限改成 0.49，判定变成 `VIOLATED`。

现实 outcome 没有变化，变的是写在规则里的线。

普通程序当然会计算 `0.5 <= 0.49`。

真正重要的问题是：**为什么是 0.49？谁有权画这条线？承担 0.5 损失的 C 是否参与？**

## 在 Agent 时代，CCM 的价值反而更大

Agent 越强，错误目标被高效实现的风险越大。

如果一个 Agent 的目标只是“最大化我的利益”，它可能非常优秀地完成任务，同时把第三方成本、退出困难、长期信任损害和不可逆后果当成外部性。

因此更合理的结构不是 `CCM vs Agent`，而是：

```text
Human / Organization
        ↓
Purpose
        ↓
CCM framing
actors / interests / burdens / hard constraints / unknowns
        ↓
AI / Agent planning and execution
        ↓
CCM re-check
evidence / third parties / direction / irreversible effects
        ↓
execute / pause / downgrade / reject / renegotiate
```

**AI 提供认知能力。Agent 提供行动能力。CCM 提供竞争合作治理。**

## CCM 也不是什么

CCM 不替代：

- 大模型的通用推理、搜索、编程、视觉和数学能力；
- Agent 的工具调用与长链执行；
- 专业领域知识；
- 现实主体的价值选择、合法授权与责任承担。

它专门处理更容易被任务目标吞掉的一层：**多主体关系、第三方代价、硬边界、未知、不可逆性、正当性与证据治理。**
