# Public Outreach Wave 4 — China + International

Date: 2026-09-13

Purpose: expand the public-idea entry in China and internationally at the same time. This wave is not a software-test campaign. It presents the project first as a more explicit, challengeable way to reason about competition and cooperation, then links to the open implementation and public testing.

Evidence discipline: `SENT` means the authenticated Gmail account accepted the outgoing message. It does **not** mean delivered, opened, forwarded, published, endorsed, or adopted.
