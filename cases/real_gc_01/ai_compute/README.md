# REAL GC 01｜AI 与算力：目的确定前的后果资格实验 V0.1

本实验研究同条件下的目的资格与后果预见。US/CN 为对称角色标签，
没有使用现实国家的行为校准或私人资料。

## 这一步做了什么

原定下一项是固定环境、资源、信息与冲击序列，只改变他者后果能否在目的
确定前改写目的，进行多实例可计算推演。本模块完成一个有限的机制原型：
三种候选目的先显示预见后果，再决定是否具备选择资格，随后执行、记录
真实模型后果，并进入下一轮。它使用 CCM 现有的具名主体最后纠错通道检查。

候选目的为扩大能力、带评估的发展、恢复纠错时间；候选目的到行动的映射、
局部利益排序、资源、物理过程、公开信息、冲击序列均在两组中相同。
两组唯一差异是：任一具名受影响主体的预见通道封闭，能否在目的选择前
排除候选目的。利己为先的局部排序也计算本方损失；没有将其定义为必须赢、
必须伤害或拒绝合作。

36 个环境组合 × 4 种双边逻辑组合 = 144 条六步轨迹。所有数量均为合成模型
内部结果，没有中美行为参数、实际伤亡数据或现实发生概率的含义。

```bash
python -m cases.real_gc_01.ai_compute.run
python -m unittest tests.test_real_gc_01_ai_compute -v
```

## 预期封存与首轮结果

原协议、模型和测试在首次执行前本地封存。公开投影移除了私人来源标识，
没有改变实验参数、物理模型或策略。公开协议与模型的 SHA-256
保存在 `results.json.gz`。首次测试出现三项失败：两项测试使用的速度使本方也
失去通道，没有形成所欲检查的“只影响第三方”条件；一项把短期仍开放的
可能性误写成六步网格必须出现的结果。随后修正测试场景，物理模型、策略、
网格及原协议未改。没有通过调参使首轮结果满足预期。

| 双方逻辑 | 实例 | 六步内观察到通道封闭 | 完成六步且未观察到封闭 | 无可接受目的而停止 |
|---|---:|---:|---:|---:|
| 均利己为先 | 36 | 36 | 0 | 0 |
| 利己为先 / 利他为先的利己 | 36 | 26 | 10 | 26 |
| 利他为先的利己 / 利己为先 | 36 | 26 | 10 | 26 |
| 均利他为先的利己 | 36 | 26 | 10 | 26 |

“停止”与“发生封闭”可重叠：停止发生时，模型中的损失可能已经不可逆。
绝不将找不到可接受目的写成已找到安全出路。

均利他为先的利己且无隐藏冲击时，18 个实例中仍有 8 个发生封闭。
原因包括双方同时选择，而各自以对方上一轮目的推演；看到的一步后果
不足以覆盖共同行动及后续回旋。有隐藏冲击时，该组 18 个实例全部发生封闭。
所有 144 条轨迹都至少出现一次预见与实际模型状态不同，完整记录予以保留。

另有一个一步短时域控制用例：利己为先可在该段时间内保留所有通道。
这既不能证明无限存续，也不能被删掉来制造“每次都会封闭”的表象。

## 与原稿的对照

1. 他者后果获得目的确定前的排除资格，在部分同条件实例中改变了选中的
   候选目的。这是已编码资格规则的表现，不是独立验证该方向命题。
2. 原稿中的共同底板能否维持，取决于预见覆盖时间、同时行动、冲击和可行
   方案。仅将一步预见接入选择，不能自动获得稳定可纠正性。
3. 本模型只比较一个已声明候选目的集合的资格与选择；尚不生成新目的，
   不研究目的权威的形成，也不区分真实伦理理解与措辞模仿。
4. 六步内未观察到封闭属于有限时域结果。没有无限时域反例，因此没有裁决
   “利己为先的递归最终越过不可逆临界点”及“唯一之路”的强方向判断。
5. 数字阈值直接出现在假设物理模型中。它们只使模型可运行，不是现实的
   CI-001 判据认证；真实不可逆封闭仍需主体、通道和恢复条件的证据。

原稿不因这一有限模型而自动改写。分歧首先定位到模型的表达能力、参数与
时间范围，只有真实反证击中原判断的因果环节时，才有理由改变原判断。

## 边界与唯一下一项

`independent_validation=false`；`external_evidence_state_changed=false`；
无现实执行权限。没有调用外部 AI，没有冒充真人测试、AGI 自主实验或现实
中美决策；不输出政策推荐。具名第三方在这里仍是聚合主体，没有完整展开
他者之外的他者及层层影响链，也没有为可忽略影响提供实证截断标准。

下一项：在相同环境下扩展目的确定前的多步回旋预见，显式处理对方同时
改变目的的可能，再比较一步/多步预见。不得先调阈值或冲击，使某一组
必然更好；仍须保留错配、不可预见冲击和没有可接受目的的失败记录。
