# 当谈判的起点改变

## AGI时代中美深度合作的一次思想推演

作者：子君赋｜出品：文明跃迁研究组

REAL GC 01｜公众思想推演稿 V1.0｜2026年9月25日

不是先各自决定怎样赢，再研究能否合作；而是在包括自己在内的人类共同未来中，重新决定什么值得赢。

## 一、先让一个没有坐在桌边的人出现

想象一场尚未发生的风暴。

在某个资源有限的沿海地区，一位母亲听见广播，却不知道广播中的地名是否包括自己的村庄；一家医院得到预警，却不知道转移病人需要的车辆能否抵达；一位气象员看见两套先进模型给出不同结果，却无从判断差异来自哪里。

与此同时，中美双方的谈判者正在讨论人工智能合作。

桌上有算力、数据、市场、知识产权，也有彼此真实的安全顾虑。那些没有坐在桌边的人，会以什么身份出现？是潜在客户、合作成本、影响声誉的因素，还是有资格影响合作目的的人？

这一次，只改变这个起点。

场景、对话和拟议条款均为思想推演，不是会谈实录；未来AGI能力是条件设定，不是已经实现的能力报告。

现实入口确实存在。中国外交部公布的2026年9月24日会谈纪要，记录了新的经贸联合安排，以及开展AI风险与收益对话的表述；纪要中双方谈及AI合作，但它不是一份已落实的灾害预警合作协议。[1] USTR在会前的公开声明也同时表达互利贸易与本国农民、制造商、劳动者的利益诉求。[2]

本文据此选择一个具体问题：双方能否把AI灾害预警合作，从技术与市场交换，推进为共同创造有效安全能力？

这并非从零发明国际合作。世界气象组织等机构推动的“全民预警”已经强调风险认识、监测预测、预警传播和准备响应四个相接的环节。[3] 本文要展示的不是谁首次想到救人，而是：当利益发生冲突，什么理由能够重新打开已经形成的目标。

## 二、给两种出发点同一份材料

设定双方得到完全相同的事实材料：两边的观测、模型和应用经验各有长处；信息互补可能改善预警，但不能预先保证效果；有的地方缺的并非另一张预测图，而是听得懂的信息、可靠的通信和行动能力；共享不当会带来安全与依赖风险；预算有限，企业需要合理收益，当地机构不愿成为无法退出的附属者。

两种推演也拥有相同的AGI辅助条件：可以关联已有材料，展开灾害、通信、交通、医疗和供应链之间的影响，生成多种安排，解释未知与分歧。它不能读懂人的内心，不能凭空补全事实，也不能代替各方作出承诺。

双方的预算、安全边界与谈判时间保持相同。不让右边凭空多出钱、更好的模型或一个绝对可信的对手。

这一能力设想有现实支点，但不是现实能力的等号。WMO已介绍AI在预测、影响分析、传播等环节的用途，同时强调数据、物理科学、业务基础设施与人的专业判断仍不可替代。[4]

两边都可以有远见，都能考虑声誉、互惠、违约和后果回流。我们不把“利己为先”写成一种愚蠢，也不把现实中的美国和中国分别放进两个道德格子。

真正不同的是最后一个问题：

他者的真实处境，是否必须先换算成“对我有用”，才有资格改变我的目标？

## 三、第一张桌子：怎样通过合作，更好地实现我方目标

在第一种推演中，双方先分别确定任务：保护本国公众、提升本国技术与产业能力、获得可持续收益、避免不可接受的安全暴露。共同安排首先需要证明它如何帮助实现这些目标。

这张桌子并不注定失败。

美方可以提出模型服务、设备和市场机会；中方可以提出观测合作、应用场景和共同研究；双方都可以主张公开基础预警，也都可能支持资源有限的地区。一个精于长期利益的谈判者，完全能够看见帮助他者的价值。

AGI在这里可以把账算得更远：封闭接口可能导致重复建设，排他市场可能刺激替代联盟，把预警变成筹码可能损害信用。它也可以找出比原先讨价还价更好的互惠安排。

但是，只要本方优先仍具有最终决定权，讨论便会在一个节点收紧。

假设同一份材料显示：项目已经能够服务双方本国和付费市场；再把某个缺乏购买力的地区纳入基本服务，需要挪用一部分推广预算、减少某项排他收益。这样做可能有长期回报，但目前无法可靠证明，也不能承诺它最终使本方财务更好。

这时，一种与该规则相容的答复是：

“我们认可这项需要。请先说明它怎样服务我方已确定的目标，或者由谁承担额外费用。现有合作不应因这项尚未落实的需求而改变。”

这个地区并没有被宣布不值得帮助；它只是没有取得改变主合同的理由资格。援助可以另议，项目可以日后扩展，眼下的基本排序仍然保留。

问题不在于双方不懂后果，而在于哪些后果必须被接受为改变目的的理由。

如果这张桌子最终也把该地区纳入服务，应如实记录。可能是它看见了足够的长期回报，可能是已有公共责任直接约束了选择，也可能是本文对其出发点的理解并不准确。不能为了制造对照，把合作从左栏删掉。

## 四、第二张桌子：先决定我们共同值得完成什么

第二种推演不要求任何一方先作单方面让步。双方带着相同材料、资源与边界，改变的是形成任务的次序。

先问：面对已经能够预见、却仍可能无法避免的损害，我们共同应当形成什么能力？本方怎样在其中安全地发展，并获得合理收益？

本次推演中，最大的他者是包括中美双方在内的人类整体。它不是坐在两国旁边的第三个国家，也不是可以将所有人的得失简单相加的总分。它意味着双方不能把自身发展放在人类共同未来之外，也不能以整体名义抹去具体人的处境。

于是，当地气象员、医院、通信服务者、劳动者与居民，不必先成为大客户或战略伙伴，才能使问题进入目标形成。

以下对话为构造的谈判片段：

当地代表：“我们不是没有收到过预报。我们需要知道预报适不适用于这里，信息能否抵达，出了错找谁纠正。”

中方代表：“那么，提供预测还不是这项合作的终点。”

美方代表：“企业收入和技术安全仍要解决。但可以先区分基本预警需要与增值服务，不把两者绑成一个进入条件。”

共同主持者：“先把人需要的能力写清，再讨论各方怎样提供、怎样分担、怎样受益。”

AGI没有替他们宣布何为正义。它帮助显示：增加模型精度、降低翻译成本、建立离线传播、改善医院响应，可能是同一个问题的不同环节；把预算全部投向领先指标，未必最能补上真正缺失的能力。

各方于是可以在相同预算内重新比较：少做一些重复展示，是否足以支持当地适配？开放最低必要接口，是否能保住商业服务同时降低依赖？独立保留两套模型并显示分歧，是否比统一一个看似更高效的系统更可靠？

这些都不是免费午餐。是否值得，需要继续判断。但此时，受影响者不再只是被事后评估的对象，而成为能够改变合作任务的人。

## 五、把立场变化写成一句实际不同的条款

两张桌子都可能写出“加强AI合作”。真正的差别要落在后面。

第一种目标下，可以形成这样的拟议条款：

双方在保护技术安全和知识产权的前提下，交换约定的预测产品，改善本国与商定市场的预警服务，并依据可确认的互惠条件协商扩大覆盖。

第二种目标下，可以形成另一种拟议条款：

双方与参与地区共同界定基本预警需要，在经各方认可的资源与安全边界内，以预警可用、能够行动和可以纠错为共同任务；商业回报、贡献分担和技术竞争围绕这一任务安排。无购买力或无对等技术，不单独构成排除基本预警需要的理由。

第一条不是坏协议，第二条也不是写上去就会生效。可见的差异是：前者以已经确定的本方任务为扩展依据；后者让共同需要进入任务本身，并据此重排本方要争取的东西。

同一方的立场可能由此发生以下变化：

| 谈判问题 | 本方优先决定目标时，可提出的立场 | 人类整体及受影响者进入目标形成后，可提出的立场 |
| --- | --- | --- |
| 我方究竟要赢什么？ | 争取更多市场、技术收益与相对优势，并通过合作降低本方风险。 | 争取本方在解决共同问题中更强的创造力、可靠性与合理收益，不将使他方依赖作为成功条件。 |
| 用什么交换？ | 主要比较数据、技术、市场和承诺的互惠价值。 | 先比较任务需要哪些能力，再组合贡献、许可、服务与资金，不要求每方交出同一种筹码。 |
| 谁能改变覆盖范围？ | 依据本方目标、对价、既有义务与预期回报审议。 | 实际承担后果的人可提出需要与异议；缺乏筹码不等于没有改变议程的资格。 |
| 哪种领先值得保留？ | 可以把独占接口或影响对方使用能力保留为谈判优势。 | 保留产品、算法与服务竞争，同时比较独占是否妨碍基本任务及当地的持续能力。 |
| 不确定的他方代价怎么办？ | 根据本方风险与已承担义务，决定调查、保留或暂缓。 | 重大未知本身可触发共同查明、有限推进与纠错安排，不要求他方先证明其损失必会回到我方。 |
| 关系恶化时还保留什么？ | 依本方收益、安全和既有承诺重新评估合作。 | 安全审查仍可收紧；但把最低必要、经核验的救生信息与无关商业争端分开处理。 |

这张表记录的是规则差异可能形成的立场，不是对现实国家行为的预测。右栏不是左栏永远想不到的发明目录。

多出的不只是方案，还可能是目的；退出竞争的也不一定是某个国家，而可能是某一种不再值得追求的胜利。

## 六、第二种出发点也必须回答难题

如果故事只停在互惠，长期利己完全可能走到同一个地方。要看清区别，必须把不方便的条件留下。

### 当对方不能回报，也无力反制

在一个明确的思想条件下，纳入资源有限地区会增加可负担的成本、减少部分排他收入；它不危及本方基本安全，却没有可确认的净回报。不能悄悄补进“声誉最终一定增值”，把困难抹平。

此时，若本方额外收益具有最终优先，暂不纳入可能符合第一种规则。第二种规则则不能仅因没有回报，就取消那些人的基本需要；它必须重审任务和支出，寻找可持续的覆盖方式，并向本方公众说明承担了什么、为何值得。

这不是证明双方财务都更好，而是承认什么有资格使双方重新判断“更好”。

自利不是被取消了。提供者也必须能够持续存在、承担本国责任，并对资源使用负责。利他为先不是无上限支付，更不是把本国弱势者的基本保障让给别人后宣布自己更高尚。

### 当合作反而增加风险

设双方提出把所有预测、数据和发布权集中到一个共同平台。新的材料却显示，它可能形成共同故障、数据滥用或当地无法质疑的单一权威。

第二种出发点应当允许拒绝这个“更深的合作”，改为有限互操作、多套模型与独立核对。不得因合作之名而压下反例。

这时方案可能更少，而不是更多；少掉的是把共同脆弱伪装成共同能力的选项。

### 当一方仍坚持原来的优先次序

新出发点可以由一方先用于审视自身目标，却不能替另一方承诺。单方采取它，不保证协议达成，也不要求提前交付不可收回的敏感能力。

可以先提出无需对方配合即可完成的服务，或者与愿意参加的其他主体合作；需要共同投入的部分，则必须明确各方承诺、权限与可撤回条件。若对方利用安排造成危险，可以暂停危险部分，不能将坚持合作变成否认风险。

### 当“为了人类”压过了当地人的声音

资源有限的地区可能拒绝方案：它不愿交出人口位置，不同意外部系统决定撤离，也不接受以长期依赖换取眼前服务。

这不是需要被清除的阻力，而是重新设计的理由。中美不能先替人类定义需要，再要求具体的人服从。未来世代不能到场，也应以公开理由、不同情景和可质疑的代表方式考虑，不能由AGI宣称已替他们发言。

人类整体不是一张空白授权书。它越是最大的参照，越不能成为忽略具体人的理由。

## 七、AGI加持的，是哪一种文明能力

设未来能力进一步增强。同样的模型、推演与组织能力，可以被用于更快识别对方的弱点，也可以用于发现双方都没有写进诉求的新任务。

在新的出发点下，AGI有三种值得展示的用途。

首先是把不同人的困境连起来：预报已经足够好，而信息没有抵达；信息抵达了，却没有交通和药品；现场行动了，却无法把错误反馈回模型。这样，“再提高一个领先指标”的目标，可能让位于“补上影响生命的断点”。

其次是展开过去难以同时讨论的组合：在同一份资源约束下比较技术许可、当地培训、商业服务、离线接口和多方核验。它增加的不只是计算速度，也可能是人们形成共同任务的能力。

再次是保存共同经验：下一次风暴到来时，谁曾指出错误，哪些办法在当地可用，怎样解释分歧，怎样把技术转成行动，都不必从零开始。

但AGI本身不保证这个方向。更强的能力既能放大共同创造，也能放大排除与控制。扩大可见范围，是机会；让这些可见的他者真正影响目标，是另一项选择。

因此，这次谈判的潜在后果不只是一份服务合同。它可能形成一条面向未来的能力链：

共同识别问题 → 共同生成任务 → 多方各展所长 → 结果接受质疑 → 有效能力留在社会。

当地区逐渐拥有自己的判断与行动能力，中美获得的未必是更牢固的依赖者，而可以是更能共同创造的伙伴。贡献仍有价值，收益仍需谈判；但“让别人永远离不开我”不再是唯一值得维护的商业或战略想象。

## 八、CCM应该怎样把这个差别交给世界

CCM，即竞争合作可计算机制研究，不必先让读者安装软件。它可以先给人一张能读懂、能改动的对照表：同一个事实，分别在两个出发点下经历了什么，为什么改变了目标，又为什么留下了某个选择。

最简单的用法，是选一个现实议题，写清共同事实和各自不可回避的责任；让双方与受影响者分别提出需要；再用两种规则生成目标、立场和方案；最后保留让结论难堪的条件。没有改变，就写没有改变；改变的只是分配，就不声称改变了目的。

这不是用表格替代人的判断，而是让判断的来路可以被看见。

有人不能回报我，他是否仍然能改变我的决定？有人不在谈判桌上，他是否仍然有资格影响目标？合作出现风险时，我是否允许它被拒绝？

不需要给出政治立场。指出这三问中的一个漏洞，就已经能够推动研究。现有CCM入口也接受只读分析、证据核对和私下反馈，无需先接受整个理论体系。[5]

本研究的方向主张是鲜明的：让利他为先的利己取代利己为先，成为人类社会运行与AGI目标形成的底层逻辑，是摆脱“为了安全不断削弱他方、又因他方反制而继续加码”、守住共同未来的唯一之路。判断保留，反证入口同样保留；这篇有限的思想推演不冒充终局证明。

请尤其提出这样的反例：在相同能力、资源、低互信、权力不对称与无可确认回报的条件下，另一种出发点如何仍能稳定地让受影响者与共同未来改变目标。也请指出本文右栏可能隐藏的强制、依赖或不必要牺牲。若其确实存在，必须修改方案，而不是修改名字来保存结论。

开篇那位母亲，不必知道两国交换了多少筹码。

她需要知道，收到的信息是否与自己有关，是否有地方可以求证，是否有人在安排能够抵达的帮助。

谈判若能让这些问题进入目标形成，它就不只是决定谁从世界得到更多，也是在决定：我们拥有的新能力，要把世界带到哪里。
