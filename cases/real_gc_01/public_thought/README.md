# 当谈判的起点改变
## When the Starting Point of Negotiation Changes

**[中文全文 V1.1](WHEN_THE_STARTING_POINT_CHANGES_ZH_V1_1.md) · [Read the full English essay V1.1](WHEN_THE_STARTING_POINT_CHANGES_EN_V1_1.md)**

同一份事实，同样的能力、预算与安全边界。如果没有坐在桌边的人，也能在目标锁定之前影响合作要完成什么，谈判者会争取什么不同的东西？这篇以灾害预警为场景的公众思想推演，不把另一种出发点缩减成更精明的利己，也不把“为了人类”变成压过具体人的理由。

The same facts, capabilities, budgets and security limits. If people outside the room can help shape what cooperation is for, before its goals are fixed, what might the negotiators seek differently? This public thought experiment uses disaster early warnings to explore a change in purposes—not merely better bargaining over existing demands. Humanity includes the negotiating parties; it is not permission to override the people affected.

**一个问题即可 / One question is enough:** 没有可确认回报时，他者的需要是否仍然能改变目标？请给出反例，或指出拟议安排可能隐藏的强制、依赖及不必要牺牲。When no return can be established, can others’ needs still change the goals? Offer a counterexample, or identify coercion, dependency or needless sacrifice hidden in the proposed arrangements.

这不是对所有反证的限定：仍然利己优先、却能在明确范围内有效避免所讨论的不可逆封闭的不同机制，也可以挑战本文的唯一性主张；不必先采用本文的目的形成方式，不能因其成功而将它重新命名归入本文。

That question does not limit the counterexamples admitted. A different mechanism that retains self-interest first yet demonstrably avoids the irreversible closure at issue within a stated domain can challenge the essay’s uniqueness claim. It need not adopt the essay’s goal-formation rule, and success is not grounds for relabeling it as that rule.
